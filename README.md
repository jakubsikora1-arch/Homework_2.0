# Homework Helper — Pracovní deník

**Koncept:** Editorial / workshop notebook

Vypadá jako osobní pracovní zápisník: papírová textura, redakční serifový titulek, ostré hrany a oranžové značkovací tahy.

## Spuštění
- Otevři `Index.html` přímo v prohlížeči, nebo nahraj celý obsah této složky na GitHub Pages.
- Bez build procesu, frameworku, npm i backendu.
- `styles.css` obsahuje základní styly aplikace a specifickou vizuální vrstvu konceptu.
- `app.js` obsahuje funkce aplikace extrahované z předchozí integrované verze.
- `assets/homework-helper.svg` je vlastní ikona.

## Poznámky k ověření
- JavaScript je dodán jako samostatný soubor.
- Před produkčním nasazením ověř na cílovém iPhonu navigaci, výběr grilu, výpočet výsledku a doporučení pračky.
- Programová data pračky jsou zachována z podkladového projektu; viz `wash.json`.
- Rozhraní nevyžaduje externí ikonovou knihovnu. Google Fonts původní verze lze odebrat, pokud chceš zcela offline provoz.

## Nasazení na GitHub Pages
Nahraj `Index.html`, `styles.css`, `app.js`, `wash.json` a složku `assets/` do samostatné složky nebo repozitáře. Pokud má být koncept hlavní aplikací, přejmenuj `Index.html` na `index.html` (GitHub Pages používá standardně malé `index.html`).
